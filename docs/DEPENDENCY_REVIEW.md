# Frontend dependency review

Reviewed November 14, 2026 against the installed lockfile and actual application code. No dependency versions were changed during integration. `npm audit` currently reports five package entries: one critical, one high, and three moderate.

| Installed package | Assessment for this application |
| --- | --- |
| `maplibre-gl` 5.24.1 | The critical advisory's broad `<=6.4.0` range includes this version, but the official **5.24.1 release explicitly backports the relevant fix**, plus subsequent sanitizer hardening. Installed source confirms snapshot-based attribute handling and sanitized DOM-node insertion. The audit range does not reflect this newer v5 backport. [Official release](https://github.com/maplibre/maplibre-gl-js/releases/tag/v5.24.1), [advisory](https://github.com/maplibre/maplibre-gl-js/security/advisories/GHSA-jrc7-96c5-q579). |
| `vite` 5.4.21 | The reported findings concern development-server behavior. Current configuration binds to `localhost`; this Mac does not execute the Windows editor paths described by several advisories. No custom Vite middleware or imports matching the system-path traversal precondition were found. These scope checks do not remove the package advisory. A patched follow-up would require a major-version change, with 6.4.4 the closest documented patched line. [Path-traversal advisory](https://github.com/advisories/GHSA-rq7h-c2jc-7f22), [Vite 6.4.4](https://github.com/vitejs/vite/releases/tag/v6.4.4). |
| `esbuild` through Vite | Its advisory concerns esbuild's own `serve` API and permissive CORS. The application uses Vite's server and esbuild's compiler, with no direct esbuild `serve` call. [Maintainer advisory](https://github.com/evanw/esbuild/security/advisories/GHSA-67mh-4wv8-2f99). |
| `react-router` / `react-router-dom` 6.30.6 | The SSR hydration issue does not apply to this `HashRouter`/`createRoot` declarative application. Navigation targets are fixed internal paths or paths containing backend-generated club slugs; no raw attacker-supplied return URL is passed to navigation. The separate open-redirect advisory therefore has no identified path through the current callers. Package advisories remain; the documented patched router line starts at 7.18.0. [SSR advisory](https://github.com/remix-run/react-router/security/advisories/GHSA-337j-9hxr-rhxg), [redirect advisory](https://github.com/remix-run/react-router/security/advisories/GHSA-wrjc-x8rr-h8h6). |

The map's attribution control is enabled and consumes the third-party OpenFreeMap style. Its sanitizer path is active; the MapLibre assessment relies on the verified **5.24.1 backport**, not an assertion that HTML attribution is unreachable. The application does not call `Popup.setHTML`; its custom marker labels use fixed building reference data.

Dependency upgrades should be a separate reviewed change with a new audit, production build, navigation checks, and map rendering checks. This integration retains the existing design and CSS. The local Vite server is a development tool, not a production deployment server.
