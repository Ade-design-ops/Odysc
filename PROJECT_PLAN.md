
# Odysc

Discover your community. Find your people.

## About
Odysc is an AI-powered platform designed to help USC students discover student organizations and simplify the club application process.

## Core Features
- Personalized club recommendations
- Searchable student organization directory
- Club profiles and membership requirements
- Centralized application tracking
- Student interest and preference matching

## Target Audience
USC students looking to get involved on campus.

## Hackathon Goals
1. Build a functional prototype.
2. Demonstrate AI-powered club matching.
3. Create a clean, intuitive interface.
4. Present a working demo.
